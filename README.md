# UNITED ASSASSINS ASSOCIATION — NMH Accessibility OS

This repository contains legacy AutoIt scripts and releases for the No More Heroes accessibility tool. The project provided configurable hotkeys and macros for No More Heroes 1, 2, and 3.

> **Please note:** The included scripts and executable are provided as-is. They may not work reliably on current systems, and no fixes or support are planned. For the maintained version, use Combo Remapper.

## Legacy files

- AutoIt source files (`.au3`) are retained for transparency and reference.
- The included executable (`.exe`) is an older, unsupported build.

## Accessibility note

This macro suite was developed with AI assistance to help accommodate physical accessibility needs. It may not work perfectly in every game, system, or configuration.
